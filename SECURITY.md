# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest on main | ✅ |
| older tags | ❌ (use latest) |

## Reporting a Vulnerability

Email **wangguigui@correctover.com** (PGP available on request). Do not open a public issue for security reports.

- Include a minimal reproduction; we replay before responding.
- First response target: 72h on business days.
- Coordinated disclosure: we publish findings jointly with the reporter, with fingerprints removed until remediation.
- We do not pay bounties; we credit researchers by handle in VERIFIED_BY.md / release notes.

## Scope

This repository's code and published datasets only. Claims about third-party systems are out of scope for this policy.
